# Archives

`outil-rentabilite/` : l'ancien outil de calcul de rentabilité (« matrice », landed cost), qui occupait la
racine du dépôt avant Filmable. Il n'est plus déployé depuis ici. Il est gardé tel quel, avec son historique git ;
pour le relancer : `cd archives/outil-rentabilite && npm install && npm run dev`.
